Politique de confidentialité

Ces scripts personnels agissent uniquement dans le compte Google de leur propriétaire, qui est aussi leur seul utilisateur.

  • Données lues : les conversations Gmail (date, expéditeur, étoile, statut lu) et les dossiers Google Drive du compte, seulement pour les ranger ou les renommer.
  • Stockage : aucune donnée n'est copiée ni conservée hors du compte Google.
  • Partage : aucune donnée n'est transmise, vendue ni partagée avec un tiers.
  • Révocation : l'accès peut être retiré à tout moment depuis la page « Applications tierces » du compte Google.

L'usage des données reçues des API Google respecte le règlement de Google sur les données utilisateur des services API, y compris ses exigences d'usage limité.

Politique de confidentialité

Ces scripts personnels agissent uniquement dans le compte Google de leur propriétaire, qui est aussi leur seul utilisateur, et dans les comptes Google Ads auxquels ce compte a accès.

  • Données lues : les conversations Gmail (date, expéditeur, étoile, statut lu) et les dossiers Google Drive du compte, seulement pour les ranger ou les renommer.
  • Google Ads : les rapports de performance (dépenses, clics, conversions) et les réglages des campagnes, seulement pour les analyser et les modifier à la demande du propriétaire. Les listes de clients envoyées pour les audiences sont chiffrées (SHA-256) avant l'envoi.
  • Stockage : les données Gmail et Drive restent dans le compte Google. Les rapports Google Ads peuvent être enregistrés sur l'ordinateur du propriétaire ou dans ses tableurs Google Sheets, pour son seul usage.
  • Partage : aucune donnée n'est transmise, vendue ni partagée avec un tiers.
  • Révocation : l'accès peut être retiré à tout moment depuis la page « Applications tierces » du compte Google.

L'usage des données reçues des API Google respecte le règlement de Google sur les données utilisateur des services API, y compris ses exigences d'usage limité.
